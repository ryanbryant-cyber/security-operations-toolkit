# Windows DFIR Incident Timeline Lab

A hands-on Digital Forensics and Incident Response (DFIR) project focused on reconstructing a fictional Windows security incident from multiple endpoint evidence sources.

## Project Goals

This project will demonstrate how a security analyst can:

- Review multiple types of endpoint evidence
- Normalize timestamps from different sources
- Correlate related security events
- Reconstruct an incident timeline
- Separate confirmed evidence from analyst assumptions
- Identify potential initial access, execution, persistence, and follow-on activity
- Document investigative findings
- Recommend containment and additional forensic actions

## Planned Evidence Sources

The fictional investigation will include:

- Windows authentication events
- Process creation events
- PowerShell activity
- File-system activity
- Network connections
- Windows service creation
- Defender/security alerts

## Investigation Workflow

Evidence Collection  
↓  
Artifact Review  
↓  
Timestamp Normalization  
↓  
Event Correlation  
↓  
Timeline Reconstruction  
↓  
Analyst Assessment  
↓  
Response Recommendations

## Safety

All hosts, users, IP addresses, commands, files, and events used in this project are fictional or reserved for documentation and testing.

No malware will be executed and no production systems or live credentials are involved.

## Final Investigation Report

The completed DFIR case study consolidates the multi-source evidence, incident timeline, investigative findings, confidence assessments, containment priorities, MITRE ATT&CK context, and final analyst conclusion.

# PCAP Network Forensics Investigation Lab

A hands-on network-forensics project focused on analyzing a synthetic packet capture and reconstructing suspicious network activity from packet-level evidence.

## Project Goals

This project will demonstrate how a security analyst can:

- Inspect packet-capture evidence
- Identify hosts and network conversations
- Filter traffic by protocol
- Analyze TCP connection behavior
- Review DNS and HTTP activity
- Identify unusual ports and communication patterns
- Reconstruct a network activity timeline
- Extract network indicators
- Separate confirmed evidence from analyst assumptions
- Document investigative findings

## Planned Evidence

The synthetic capture will contain a mixture of:

- Normal DNS traffic
- Normal HTTP/HTTPS-style connections
- Internal system communication
- Repeated connection attempts
- Suspicious external communication
- Unusual destination ports
- Network activity requiring analyst correlation

## Investigation Workflow

Synthetic PCAP  
↓

↓

↓

↓

↓  
Response Recommendations

## Safety

All IP addresses, domains, systems, and network activity used in this project are synthetic, private, or reserved for documentation and testing.

No unauthorized network traffic or live malicious infrastructure is involved.

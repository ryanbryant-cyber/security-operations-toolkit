# IOC Enrichment & Triage Tool

A Python-based cybersecurity analyst project designed to validate, normalize, correlate, and triage Indicators of Compromise (IOCs).

## Project Goals

This project will demonstrate how a security analyst can use Python to:

- Identify common IOC types
- Normalize indicator data
- Detect duplicate indicators
- Correlate related security observations
- Assign basic analyst risk scores
- Generate investigation recommendations
- Export structured results for additional analysis

## Supported Indicators

The initial version will support:

- IPv4 addresses
- Domain names
- URLs
- File hashes

## Project Status

🚧 In Development

This project is part of the Security Operations Toolkit and is being developed as a hands-on cybersecurity learning exercise.

## Safety

All sample indicators and datasets used in this project are fictional, sanitized, or reserved for documentation and testing purposes. No production credentials, private organizational data, or sensitive information are included.
